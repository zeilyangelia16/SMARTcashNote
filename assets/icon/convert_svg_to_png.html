Pilih file SVG untuk melihat preview
Langkah Penggunaan:
  1. Pilih file SVG (atau gunakan logo default)
  2. Sesuaikan ukuran jika perlu (default 1024x1024)
  3. Klik tombol konversi
  4. Download file PNG yang dihasilkan
  5. Letakkan di: assets/icon/icon.png
  6. Jalankan: flutter pub run flutter_launcher_icons
ℹ️ Tips: Jika tidak ada file SVG, gunakan tombol "Download Logo Default" untuk mendapatkan logo CashNote V3 yang sudah siap.
